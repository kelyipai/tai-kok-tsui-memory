# 大角咀記憶 | Tai Kok Tsui Memory

一個懷舊風格嘅靜態網站，介紹香港大角咀由七十年代到而家嘅變遷。

## 內容分組

- **學校**：中華基督教會銘基書院、路德會沙崙學校、中華基督教會基全小學、晏架街遊樂場足球場
- **生活**：麗華戲院、金冠戲院、大角咀碼頭、紅寶石酒樓、慶華酒樓、寶華酒樓、七記冰室、大角咀舊大牌檔、富多來中心
- **居住**：中匯街、中美樓、中英樓、必發道、必發大廈

## 設計風格

網站採用「褪邊（Faded Borders）」視覺哲學：舊報紙質感、菲林相框、啡紅色調、不對稱排版，營造七十年代至八十年代香港社區嘅氛圍。
